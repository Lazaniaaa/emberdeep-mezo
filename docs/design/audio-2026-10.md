# Approved synthesized audio — 2026-10-25

The owner's `docs/audio/sound-lab.html` replaces the previous single melody and oscillator cue table.
All 50 approved sounds, the three scores and four soundscapes are synthesized in Web Audio without samples,
downloads or new dependencies. No game rules, replay state, prices, AI, light costs or turn timing changed.

## Implementation

| File | Responsibility |
| --- | --- |
| `src/audio/context.ts` | One hardware AudioContext, unlocked by a gesture |
| `src/audio/engine.ts` | Compressor (−14 dB, ratio 4), master .9, generated 2.4s stereo reverb, 2s noise buffer, tone/noise/clicks, voice cleanup |
| `src/audio/world.ts` | The 20 exact Sound Lab hero/world definitions |
| `src/audio/mobs.ts` | Nine species and Cerberus, each windup/strike/death (`w/s/d`), unchanged species IDs |
| `src/audio/tracks.ts` | Exact camp/descent/boss notes, instruments, envelopes and tempi (76/66/132 BPM) |
| `src/audio/ambience.ts` | Catacombs, mycelium, cinderworks, hollowglass, plus the approved heartbeat |
| `src/audio/music.ts` | One 50ms look-ahead scheduler, scene selection, sequential 0.5s out / 0.5s in transitions |
| `src/audio/use-soundtrack.ts` | App/store subscription, first gesture, mute, visibility and teardown |
| `src/audio/event-cues.ts` | Presentation-only before/after inference of species, Ward, prop kind and deaths |
| `src/audio/turn-sounds.ts` | Existing render-frame/contact queue; no input timers or action delays |
| `src/audio/sfx.ts` | Shared engine playback and legacy UI aliases; bump is the approved step at .35 gain |
| `src/audio/settings.ts`, `src/components/audio-controls.tsx` | Music/effects levels in independent `emberdeep-audio-v1` localStorage key |
| `src/audio/offline.ts`, `scripts/audio-render.mjs` | Dev-only OfflineAudioContext WAV generation and signal checks |
| `scripts/audio-smoke.mjs` | Real React game in Edge, plus a MediaRecorder capture of its actual audio graph |

The approved dry/wet levels remain FX .8/.25, ambience .8/.45 and music .55/.35; reverb return .5.
Sliders adjust music gain and both effects/ambience gains independently; their defaults are .55 and .8.
The music lowpass is `400 * 22 ** (light / maxLight)`, Q .7, with the approved .1s smoothing.
At ≤25% the heartbeat interval is `.95 - (25 - lightPercent) * .014`, with the approved crackle probability,
frequencies and gains. No ambience plays in camp. Cerberus must be awake on depth 7 for the boss score.

One score schedules notes at a time. Its input fades to zero over .5s, outgoing voices are released, and the next
score fades in over .5s. The shared reverb retains its natural tail. Paused/hidden clocks skip missed notes.
Music mute/visibility/unmount stops every tracked voice and continuous ambience source. Ended voices disconnect
their filters, gains and modulation oscillators. Simultaneous audible effect sources are capped at 24 by stealing
older sources, including future, randomly scheduled clicks; music/ambient beds have separate lifecycles.

Audio sliders use native keyboard-accessible range controls. Focusing them never submits game turns; Enter/Space
on the settings disclosure belongs to the control. No zustand save version or migration changed.

## Event mapping

| Event / presentation observation | New cue(s) | Timing / inference |
| --- | --- | --- |
| step / bump | step / quieter step | Immediate, bump gain .35 |
| hit | swing, then hit | Existing contact queue |
| kill | swing, then kill + `<species>:d` | Removed creature ID from previous floor state; contact queue |
| warn | `<species>:w` | New windup phase only; at most two warnings per observed action |
| drain | `<species>:s` + hurt | Previous windup → current recovery, old aim and current hero position |
| bossDrain | cerberus:s + hurt | No duplicate strike from the accompanying drain event |
| miss | `<species>:s` + dodge | Strike coverage misses hero |
| Ward blocks a strike | `<species>:s` + ward | Strike coverage includes hero and previous Ward was positive; no dodge/hurt |
| Ward potion | potion + ward | Ward increased |
| smash / break | swing, then urn or crate | Changed/removed previous prop; urn/sack → urn, crate/barrel → crate; contact queue |
| gold / crystal / oil / potion / levelup | Same named cue | Immediate |
| chest / vault / hoard | chest | Immediate |
| descend / extract / dark | stairs / rift / dark | Immediate |
| boss | cerberus:w, also cerberus:d when removed | Requested legacy boss mapping; contact queue. In current rules `boss` means defeat, not awakening |
| Cerberus awakens | cerberus:w | Presentation state transition, unless already covered by its new windup |
| buy / mint | buy / mint | Camp/shop action |
| sigil / ticket / gear | mint / gold / levelup | Approved primitives reused |
| sealed / nightVision / burn / lanternFull | ward / potion / stairs / oil | Approved primitives reused |

Fallback routing covers all **28 RunEvent keys**. No species is guessed from screen position or message text.
Old/incomplete states without attack phases retain generic hurt/dodge feedback rather than inventing a species.
The original hero contact clock remains unchanged; gameplay calls are never delayed for audio.

## Reproduce and listen

From the repository root, with `npm run dev` running on port 5741:

```powershell
$env:SMOKE_CHANNEL='msedge'
node scripts/audio-render.mjs http://127.0.0.1:5741/
node scripts/audio-smoke.mjs http://127.0.0.1:5741/
```

The reference page is `http://127.0.0.1:5741/docs/audio/sound-lab.html` in development. It is not a production entry.
Generated files are **local and ignored by Git**, not game assets:

- `artifacts/audio/sfx-<key>.wav`: all 20 world cues and 30 creature cues, 5s each (colons become hyphens).
- `artifacts/audio/music-{camp,descent,boss}-{100,15}pct.wav`: 30s each; 15% includes heartbeat/crackle.
- `artifacts/audio/ambience-{catacombs,mycelium,cinderworks,hollowglass}.wav`: 20s each.
- `artifacts/audio/game-edge-0.webm`: actual game audio, including menus, movement/combat, low light, mute,
  hidden-tab stop, death and return to camp. This is an audio recording, not a silent screen video.
- `artifacts/audio/game-qa.json`: actual-game lifecycle measurements; local combat/boss/phone screenshots sit beside it.

Open WAVs in the OS audio player (for example `Start-Process .\artifacts\audio\music-camp-100pct.wav`).
Listen first to **music-camp-100pct.wav**, **music-descent-15pct.wav**, **music-boss-100pct.wav**,
**sfx-chaincoil-s.wav**, **sfx-cerberus-s.wav**, then the real-game recording.

## Verification and limits

- `docs/audio-qa.json`: **60/60** unnormalized stereo 44.1kHz IEEE float WAVs: finite samples, non-silent RMS,
  peaks below 0 dBFS. Highest measured peak **−2.342 dBFS** (descent at 15%). Nothing is normalized to hide clipping.
- `scripts/audio-spec.test.ts` evaluates the owner's original JS in a sandbox and compares every tone/noise call
  of all 50 cues, every step of all three complete track loops, and ambient events/gaps/heartbeat against the port.
  Reverb/noise randomness is fixed for reproducible WAV QA, while gameplay audio remains random.
- Tests cover every RunEvent, species death/attack, two-warning limit, Ward versus dodge, prop material,
  render-contact timing, lifecycle cancellation, no catch-up, sequential track switching, scene selection,
  volume parsing and the 24-effect-source limit even with out-of-order scheduling.
- Edge checks use fresh local saves and ordinary UI to mint/equip/descend; combat fixtures place creatures on
  generated floor cells, then use real game actions. This is controlled QA rather than an unassisted playthrough.
- These are signal, parameter and browser checks, not a claim of subjective human listening approval.
- `npm run typecheck`, `npm test -- --maxWorkers=2`, `npm run build` pass; lint retains only the three known
  Fast Refresh warnings. `git diff --stat -- src/game` is empty. No server/contracts or lockfile changes.

This change itself needs **no signing-server rebuild**: all changes are audio, UI and presentation.
Previously pending rule changes still need their coordinated release. Nothing was pushed or deployed.
