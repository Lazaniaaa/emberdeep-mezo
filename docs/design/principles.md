# Принципи дизайну Emberdeep

Стисла робоча версія дослідження «Механіка цікавості» (ChatGPT, жовтень 2026; повний текст —
`docs/design/research-mechanics.docx`). Тут лише те, що застосовне до Emberdeep. Перед кожною новою механікою,
монстром чи предметом — пройти чекліст нижче.

## Головна думка

Цікаво, коли **дія змінює світ, і через це наступне рішення вже інше**. Погано: дія → число більше → та сама дія.
Для соло-розробника: **взаємодія кількох правил дешевша й сильніша за багато контенту** (5 ворогів × 6 модифікаторів
дають більше ситуацій, ніж 30 ворогів).

## Чекліст перед додаванням чогось

1. **Яке нове рішення це додає?** Немає відповіді — не додавати.
2. **Чи змінює це значення вже наявних рішень?** (Краще за просто +N.)
3. **Чи гравець може щось зробити з випадковим результатом?** Якщо «нічого» — випадковість погана.
4. **Чи після смерті ясно, що спробувати інакше?** («Я пожадібничав», а не «не пощастило».)
5. **Чи видно прогрес без цифр?** (1 снаряд → 5 снарядів, а не атака 34 → 38.)
6. **Чи core loop цікавий без XP, магазину й щоденних нагород?** Мета-прогресія не має маскувати нудьгу.

## Головний ризик Emberdeep: світло як таймер

Якщо «олія 100% → ходиш → 0% → смерть», це таймер, а не рішення. Світло має мати **кілька конкуруючих застосувань**:
бачити (радіус), відлякувати одних ворогів, приваблювати інших, відкривати цінне, позначати дорогу назад, обмінюватися
на лут. Зараз (2026-10): світло палять кроки й очікування; удари безкоштовні (2026-10-11); є Flare, Night Vision,
Oil Vial; Lantern Moth «тягнеться до світла». Напрям: більше рішень «на що витратити світло», а не довший таймер.

## Найкращі механіки за ціною (для Emberdeep)

| Що | Ідея для Emberdeep | Ціна |
| --- | --- | --- |
| Екологія світла | ворог-тінь слабшає у світлі, міль летить на світло, сліпий повзун реагує на звук: «завжди з повним ліхтарем» перестає бути оптимальним | низька–середня |
| Лут, що додає ризик | проклята реліквія: ×N до золота, але світиться/будить мисливців, поки не винесеш (найкраща ідея для 15-с реклами) | низька |
| Вибір з 3 на новому рівні | замість фіксованого бонусу — 3 варіанти, що змінюють правила (не лише +%) | низька |
| Синергії реліквій | «Масляний ліхтар» (+50% радіус, ×2 витрата, вогонь підпалює) + «Серце молі» (вбивства приманених світлом повертають олію) = окремий стиль гри | низька |
| Push-your-luck | момент «вийти зараз чи ще одна кімната» має бути чітким і болісним | вже є, посилювати |
| Щоденний seed + таблиця | однаковий для всіх спуск дня + рекорди (соціальне без мультиплеєра); для Ember Pot seed все одно видає сервер | низька |

## Драматургія спуску (2–4 хв)

0:00 безпечно → 0:30 перша загадка → 1:00 вибір предмета/апгрейду → 1:30 перший серйозний ризик → 2:00 цінний лут →
2:10 «назад чи глибше?» → 2:30 ресурсу мало → 3:00 втеча / clutch. Погано: та сама печера, тільки важча.

## Відчуття удару (game feel), за пріоритетом

Миттєва реакція на ввід → hit-stop 50–120 мс лише на сильних ударах → короткий відкид → різні звуки удару →
3–8 частинок → цифри шкоди лише коли пояснюють → тряска екрана лише на важливих подіях. Ієрархія: якщо трясе все,
сильний удар уже не сильний.

## Як перевіряти, чи цікаво (а не питати «сподобалось?»)

Дати грати без пояснень і дивитись:
- **час до першого справжнього вибору** (коли вперше було два хороші варіанти);
- **чи сам тисне «ще раз»** після смерті;
- **чи змінює стратегію** на другому спуску;
- **чим пояснює смерть** («пожадібничав» — добре; «не знаю» — погано);
- **як описує свій білд** («через мілей і вогонь» — добре; «багато урону» — погано);
- головне питання: **коли вже можна вийти, чи хтось сам іде ще в одну небезпечну кімнату?**

| Симптом | Діагноз |
| --- | --- |
| шукає кнопку | незрозумілий інтерфейс |
| робить дію, не бачить ефекту | слабкий фідбек |
| повторює правильну дію без думки | нудьга |
| уникає системи | незрозуміла або марна |
| помирає й одразу ще раз | продуктивна поразка |
| помирає й питає «що я мав зробити?» | немає попередження перед небезпекою |

## Обмеження, характерні для нас

- Будь-яка зміна правил у `src/game/*` → оновити сервер підпису (`attest.sh`) разом із сайтом.
- Для справжніх грошей (Ember Pot) випадковість і перки мають бути чесними: золото для пулу без перків, seed від сервера.
- Не починати нову гру з нуля: «Lumen Debt» з дослідження — це, по суті, Emberdeep.
