Deploy Emberdeep on Mezo Testnet

Development only: served by npm run dev, not part of the site. It deploys the Wave 2 contracts from your own browser wallet, one transaction at a time; no key ever passes through this page. Progress is kept in this browser, so a closed tab carries on where it stopped.

1. Wallet

The wallet that deploys owns every contract (and receives the pot's 20% treasury share). It needs a little Mezo testnet BTC for gas.

2. Settings

EmberItems answers tokenURI(id) with this text followed by the token id, and the game's server answers that address with the item's name, picture and stats, which is how wallets and the Mezo explorer show a found weapon. So it must be the published site's own address, start with https:// and end with a slash; deploy/attest.sh prints it when it finishes. Leave it empty if the site has no address yet, and set it afterwards with the button below (also after moving to a new server or domain).

Market fee: of every sale, sent into the new Ember Pot's current round.
