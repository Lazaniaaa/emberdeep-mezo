# Notice and credits

Emberdeep is built with AI assistance (Claude, via Claude Code). It began as an entry to the Rare Friends Vibeathon;
this version has nothing of Rare Friends in it (no artwork, no contracts, no token).

## Third-party code

- **Solady 0.1.26** ([Vectorized/solady](https://github.com/Vectorized/solady), MIT): `EIP712` and `ECDSA`, compiled into the Hall of Descents contract.
- **Libraries:** React, Vite, Tailwind CSS, shadcn/ui on Base UI, lucide-react, sonner, zustand, viem, next-themes, Vitest, oxlint, Playwright, solc-js and the ethereumjs EVM (tests only), each under its own open-source licence (see `package.json` and `package-lock.json`).
- **Fonts:** Geist Variable and Silkscreen, via Fontsource (SIL Open Font License 1.1).

## Artwork

- **Archived dungeon floor illustrations** (`art/maps/painted/`, originals in `art/maps/original/`): supplied by the builder for this project (add the artist or tool here if it should be credited). Runtime floors now use the owner's tilesets in `art/tiles/raw/`.
- **Creature illustrations** (`art-src/enemies/`): painted pictures of the nine dungeon creatures supplied by the builder from an earlier build of this project (add the artist or tool here if it should be credited). They are kept as reference only.
- **Delvers and creatures** (`public/heroes/`, `public/mobs/`, sources in `art/`): pixel-art sprite sheets generated by the builder with AI image tools (ChatGPT, Nano Banana) from the prompts in `docs/art/PROMPTS.md`, then cut, shrunk and cleaned up by `scripts/sprite-sheets.mjs`.
- **Everything else** (the camp scene, Cerberus, items, armor, potions, Delver portraits and the interface sprites) is pixel art drawn in code for this project. Sound cues are generated with the Web Audio API.

## Economy

All balances, purchases, payouts, draws and mints are simulated USDC in the browser. The only on-chain action is a
descent a player chooses to record in the Hall of Descents on Arc, signed and paid for (gas) by their own wallet.
